# Data Sources

## NBA Stats

Access method: `nba_api`

### PlayerCareerStats

Used to retrieve Kobe Bryant's season-by-season NBA career statistics.

Kobe Bryant NBA Player ID: `977`

Raw output:
`data/raw/kobe_career_stats.csv`

The raw API output is kept unchanged. Any calculations or transformations based on this dataset will be stored separately so that the original data can always be reproduced.
